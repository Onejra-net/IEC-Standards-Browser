# IEC Standards Browser - ONEJRA

**Interactive and AI-assisted browser of IEC technical standards.**

IEC Standards Browser helps navigate IEC standards by combining topic-based tagging with integrated AI support.
The application helps identify relevant standards and explore relationships between documents throughout the engineering design process.

## Features

- Browse IEC technical documentation.
- Search and identify standards relevant to specific projects.
- Organize references and metadata.
- Work with topic-based tagging of technical standards.
- Explore relationships between standards.
- Integrated AI support for standards search and analysis.
